# Pokémon Sold Tracker

Android UK-only Pokémon card sale tracker. Save separate searches, record verified actual sold prices and compare 1 week, 1 month, 3 months and 6 months.

The ordinary eBay sold listing price is **not always the accepted Best Offer price**. This first version opens UK sold searches and uses only manually confirmed prices in averages; unattended eBay monitoring isn't supported.

APK is built by the GitHub Actions workflow, available under Actions → Build Android APK → Artifacts.
